## 3. Baseline Extraction Notes
WPF snapshots profile settings independently, restores visibility and score controls when profile selection changes, and treats manual threshold edits as overrides by disabling the corresponding automatic threshold calculation.

## 4. Changes Made
- Added a profile threshold override operation that clones new thresholds and removes stale filter-specific overrides.
- Added shared all-frame rejection revalidation and routed every Avalonia main-window threshold edit through it.
- Manual threshold edits now disable the matching auto-calculation flag before persistence.
- Completed profile-backed visibility restoration for sky temperature, mean background, and score controls.
- Added save/load, clone independence, profile override, and cross-filter revalidation regression coverage.

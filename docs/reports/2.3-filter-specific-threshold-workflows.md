## 3. Baseline Extraction Notes
WPF clones global thresholds when a filter is edited for the first time, resolves filter keys case-insensitively, persists named threshold sets in the selected profile, and evaluates every frame with its resolved threshold set.

## 4. Changes Made
- Added case-insensitive profile APIs for resolving and creating filter thresholds with global fallback.
- Changed Avalonia threshold controls to display the selected filter's values and create an independent clone on first edit.
- Named filter edits persist only that filter's threshold set and disable the matching auto-calculation flag.
- All Filters edits retain the Task 2.2 behavior: replace the selected profile's global thresholds and clear stale filter overrides.
- Initial analysis, manual apply, diagnostics, reset, and rejection reasons now resolve thresholds by frame filter.
- Every threshold edit and apply action revalidates all loaded frames, including frames outside the selected filter.
- Blank filter names are normalized to the UI's `(no filter)` scope.

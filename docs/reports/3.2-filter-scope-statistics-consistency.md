# Task 3.2: Filter Scope Statistics Consistency

## Objective
Match WPF accepted/rejected totals, integration times, and per-filter summaries for the active filter-chip scope.

## Baseline reference
- `src/ViewModels/MainViewModel.cs`: `GetAllFilteredFrames`, `GetVisibleFramesForStatistics`, and `UpdateFrameStatistics`.
- `src/Rejector.Avalonia/ViewModels/MainWindowViewModel.cs`: filter scope, result visibility, and summary properties.

## Changes made
- Restored WPF scope ownership: frame statistics follow the general filter chips, not the automatic-rejection threshold selector.
- Kept statistics independent of the Accepted/Rejected visibility toggles.
- Matched the WPF all-chips-off behavior by returning an empty frame scope instead of treating it as all filters.
- Added `FrameStatisticsCalculator` for deterministic accepted/rejected totals, ratios, exposure totals, and case-insensitive per-filter grouping.
- Normalized blank filter names to `(none)` and matched the WPF per-filter integration fallback to total exposure when no accepted exposure remains.
- Matched the WPF empty integration-time display when exposure data is unavailable.

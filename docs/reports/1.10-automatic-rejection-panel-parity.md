## Implemented
- Added reset control:
  - `ResetThresholdsCommand` and reset button (`↻`) in the panel header.
  - Resets all rejection thresholds to defaults and reapplies scope.
- Added filter selection:
  - `SelectedRejectionFilter` + `RejectionFilterOptions` with `All Filters` and discovered filters.
  - Threshold application and slider reject-count diagnostics now honor selected scope.
- Added per-slider reject count values:
  - Implemented counts for trail, FWHM(as), SQM, sky temp, HFR, eccentricity, mean background, stars, and score.
  - Wired all visible slider rows to `ShowRejectCount` / `RejectCount`.
- Added missing sliders:
  - Min. trail confidence
  - Max FWHM (as)
  - Min SQM
  - Max sky temp
  - Max HFR
  - Max Eccentricity
  - Max Mean Background
  - Min Stars
  - Min Score
- Added missing auto-stretch controls:
  - `AutoStretchPerFrame` checkbox.
  - `STF Target Background` slider.

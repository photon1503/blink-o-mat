## 3. Baseline Extraction Notes
WPF uses nearest-neighbor bitmap scaling, a layout transform so zoom changes scroll extents, pointer-centered wheel zoom, viewport-centered toolbar zoom, and left-button image capture for panning.

## 4. Changes Made
- File: src/Rejector.Avalonia/Views/FramePreviewWindow.cs
- What changed: Replaced render-only scaling with layout-aware scaling, disabled bitmap interpolation, preserved the zoom focal point, added wheel zoom, and added captured left-drag panning.
- What changed: Corrected the root grid so the FITS viewport owns the expanding row instead of a small auto-sized bottom row.
- What changed: Restored legacy preview bindings (`Left`, `Right`, `R`, `Ctrl+F`, `Ctrl+O`, `Space`) at window preview scope and removed unrequested shortcuts.
